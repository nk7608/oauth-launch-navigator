# Demo transcript

Captions for the [/demo](https://oauth-launch-navigator.vercel.app/demo) walkthrough, captured 2026-10-23 from production.

## 1. Find the app you want to connect

![Scopewise home: search box first, a diagram of agent to Composio to the user's app, and the app catalog with logos](../../public/demo/catalog.jpg)

Search by app name or website. Seven guides are ready, and any other app can be researched live. The diagram shows where your OAuth app fits: the user clicking Allow is what connects your agent to their account.

Open it: https://oauth-launch-navigator.vercel.app/

## 2. Choose access and audience

![Gmail read access for customers showing restricted-scope verification and a security assessment](../../public/demo/gmail-read.jpg)

The same app can have different requirements. Gmail read access for customers uses restricted scopes, so the approval path shows provider review and a possible customer admin step, with the wait and approvers above.

Open it: https://oauth-launch-navigator.vercel.app/plan/gmail?does=read&users=customers

## 3. See what changes for send-only access

![Gmail write-only view showing verification without a security assessment](../../public/demo/gmail-send.jpg)

Switch to Write: the security-assessment step drops out for send-only access. Changing these choices reruns fixed rules, so it uses no research credits.

Open it: https://oauth-launch-navigator.vercel.app/plan/gmail?does=write&users=customers

## 4. Follow the next action and hand off clearly

![Connection steps with the one-app-many-users diagram, You do and Agent can do tags, and copyable values](../../public/demo/setup-steps.jpg)

Steps are a timeline you can tick off. Each one says who does it, has copyable values like the redirect URI, and shows the blocker you might hit with its fix. Copy one step, the whole plan as Markdown, or a version for your AI agent.

Open it: https://oauth-launch-navigator.vercel.app/plan/gmail?does=write&users=customers#phase-connect_composio

## 5. Check the evidence before relying on a guide

![Expanded source list with Official, Tested and Inferred labels](../../public/demo/sources.jpg)

Open the sources and unknowns. Tested means a dated observation from a setup attempt; it does not certify every scope or production approval. Most guides remain unreviewed.

Open it: https://oauth-launch-navigator.vercel.app/verification

## 6. Research an app outside the catalog

![Research progress for Calendly: five stages with the source domains found so far](../../public/demo/live-progress.jpg)

Type any app. An agent checks Composio, searches the provider's docs and shows each source as it's found, then writes a plan that cites only those sources.

Open it: https://oauth-launch-navigator.vercel.app/plan/airtable

## 7. Get a saved, shareable result

![Airtable guide generated by the live research pipeline](../../public/demo/airtable-result.jpg)

That run saved seven steps with six sources and six open questions. It demonstrates generation and storage; Airtable account setup and approval have not been verified. Share links keep the selected choices, and JSON or Markdown exports support an agent handoff.

Open it: https://oauth-launch-navigator.vercel.app/plan/airtable

## 8. Keep useful facts when research is limited

![Airtable starter plan with an hourly-limit explanation, confirmed toolkit facts and a source link](../../public/demo/limited-research.jpg)

Before the retry, the hourly cap produced this labelled starter. It kept confirmed Composio facts and a source link while leaving provider requirements unknown. A later retry produced the guide above. Library and saved guides remain available.

Open it: https://oauth-launch-navigator.vercel.app/plan/hubspot
